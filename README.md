# Soccer Manager App

A football manager style game prototype with multi-year progression.

## Getting started

```bash
npm install
npm run dev
```

## Features

- Club dashboard and finances
- Squad management
- Match simulation
- League table progression
- Transfer market
- Multi-season progression across years
- Local save state in the browser

## Notes

This is a playable manager simulation prototype inspired by the football management genre, not a full commercial football manager clone.
